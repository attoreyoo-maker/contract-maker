# 쓸 사람

- 누구인가 : 온라인 쇼핑몰을 혼자 운영하는 자영업자
- 언제 : 다른 사업자에게 도매로 넘길 때
- 왜 : 계약서 양식을 찾아 작성하기 불편함
- 지금은 어떻게 : 그냥 인쇄된 양식에 손으로 작성한다


- 이 후보로 계속 가나 : [계속 간다 - 계약때 마다 계약서를 작성하는 일이 한 달에 스무 번은 된다]


**달라져야 하는 것 세 가지**

1. "언제" — 원래는 "다른 사업자에게 도매로 넘길 때"(파는 입장)였는데, 사는 사업자라면 "도매로 사올 때"로 바뀌어야 함 (역할이 반대이므로 확실).
2. "왜" — 원래 불편은 "계약서 양식을 찾아 작성하기 불편함"이었는데, 구매자는 계약서를 직접 만들기보다 받아서 확인·서명하는 입장일 수 있어 불편 내용이 같을지는 파일에 없어 짐작임.
3. "지금은 어떻게" — 원래 답은 "인쇄된 양식에 손으로 작성한다"였는데, 이건 파는 사람 기준 답이라 구매자도 지금 그렇게 하는지는 파일에 없어 알 수 없음, 새로 확인이 필요함.

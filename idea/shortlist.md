# 내 아이디어 후보

지금 가장 마음이 가는 것 : [거래처명, 금액, 날짜, 계약내용 같은 정보를 어딘가에 넣으면, 그 정보가 빈칸에 채워진 계약서 문서가 만들어져 나온다]

## 후보 1 - 문서로 만들어지는 계약서

- 무엇을 만드나 : [거래처명·금액·날짜 ·계약내용 등을 넣으면 빈칸이 채워진 계약서가 문서로 나온다]
- 누가 겪는 문제인가 : [계약때 마다 양식을 찾아 작성해야 하는 자영업자들]
- 팀이 준 말 : [00님 - 나라면 쓰겠다. 알바를 해도 계약서가 필요하다]
- 만들 수 있나 : [만들 수 있다. 입력창·버튼 화면(배울 예정)과 문서 파일 만들기(이미 해봄)만으로 이루어져 있어 지금까지·앞으로 배우는 것 안에 다 들어감.]

거래처명, 금액, 날짜, 계약내용 같은 정보를 어딘가에 넣으면, 그 정보가 빈칸에 채워진 계약서 문서가 만들어져 나온다 — 이렇게 이해했습니다.

**질문**

* "넣으면"이 화면의 입력창에 타이핑해서 넣는 건가요, 아니면 다른 방식(엑셀 파일 올리기 등)인가요?
* "문서로 나온다"는 어떤 파일 형태(워드, PDF 등)를 뜻하나요, 아니면 형태는 상관없다는 뜻인가요?

**이 문장에서 빠져 있는 것 세 가지**

1. 계약서의 바탕이 되는 양식(템플릿)을 어디서 가져오는지 — 미리 만들어둔 것을 쓰는지, 고르는지
2. 계약 종류가 여러 가지일 때 어떤 종류를 고르는지에 대한 언급
3. 다 만들어진 계약서를 이후에 어떻게 쓰는지(저장, 전달, 서명 등)

## 후보 2 - 홍보자료를 만들어주는 문서

- 무엇을 만드나 : [주제와 키워드를 넣으면 관련 자료와 글 초안을 정리해서 문서로 나온다]
- 누가 겪는 문제인가 : [자영업자들의 업소 홍보 문구를 만들 때]
- 팀이 준 말 : [00님 –자영업자면 쓰겠다]
- 만들 수 있나 : [입력창, AI에게 물어 답 받기, 문서로 저장하기가 모두 배우는 내용 안에 있음. 다만 "관련 자료"가 AI가 아는 내용으로 써주는 글이 아니라 인터넷에서 실제 자료(사진, 출처 있는 글)를 찾아 모으는 것까지 뜻한다면, 그 부분(인터넷 검색·수집)은 배우는 목록에 없어서 되는지 확실하지 않음.]

**다시 말하면**

주제와 키워드를 넣으면, 그것과 관련된 자료와 글 초안을 정리한 문서가 만들어져 나온다 — 이렇게 이해했습니다.

**질문**

* "관련 자료"는 인터넷에서 실제로 찾아온 자료를 뜻하나요, 아니면 AI가 알고 있는 내용을 바탕으로 정리해준 것을 뜻하나요?
* "글 초안"은 어느 정도 완성된 글을 말하나요, 아니면 목차나 개요 수준을 말하나요?

**이 문장에서 빠져 있는 것 세 가지**

1. 어떤 글(블로그, 홍보 문구 등)을 위한 초안인지에 대한 언급
2. 완성된 문서를 이후에 어떻게 쓰는지(저장, 수정, 그대로 사용 등)
3. "관련 자료"가 어디서 오는지(출처, 수집 방법)

## 후보 3 - 소모임 참여자를 찾아주는 일

- 무엇을 만드나 : [소모임 주제와 지역을 넣으면 참여할수 있는 사람들에게 배포되고 예약을 받아 참여자를 모집한다]
- 누가 겪는 문제인가 : [수강생을 모집하는 프리랜서 강사]
- 팀이 준 말 : [00님 – 글쎄요, 당근, 맘카페등 더 쉬운 방법이 있다]
- 만들 수 있나 : [배우는 것 중 "여러 사람이 각자 컴퓨터에서 동시에 쓰는 것"이 빠져 있는데, 이 아이디어는 정확히 그걸 필요로 함(여러 사람이 각자 다른 시간에 신청을 넣고, 그게 한 곳에 안전하게 모여야 함).]

**다시 말하면**

소모임 주제와 지역을 넣으면, 참여할 수 있는 사람들에게 그 내용이 배포되고, 신청(예약)을 받아서 참여자를 모으게 된다 — 이렇게 이해했습니다.

**질문**

* "배포"는 어디에 어떤 방식으로 전해지는 건가요(예: 인터넷 주소로 올리기, 특정 채널에 올리기 등)?
* "예약을 받아"는 신청하는 사람이 직접 입력하는 화면이 있다는 뜻인가요?

**이 문장에서 빠져 있는 것 세 가지**

1. 배포되는 곳(어느 채널, 어느 사람들에게)이 어디인지
2. 예약 정보가 어디에 모이고 어떻게 확인하는지
3. 신청받는 인원수나 마감 같은 조건을 다루는지 여부

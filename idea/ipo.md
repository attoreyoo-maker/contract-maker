# 넣으면 나온다

한 줄 : 거래처명·금액·날짜·계약내용을 넣으면 → 만든 계약서가 목록에 쌓여 여러 개의 계약서가 목록 모양으로 나온다

- 입력 : 거래처명·금액·날짜·계약내용을 입력창에 넣는다.
- 처리 : 넣은 정보로 빈칸을 채워 계약서 문서를 만든다.
- 출력 : 만든 계약서가 목록에 하나씩 쌓여서, 여러 개의 계약서가 줄줄이 나열된 목록 모양으로 보인다.
- 모양 : 만들어주는 도구
- 잘못 넣었을 때 : 거래처명·금액·날짜·계약내용 중 하나라도 비워 둔 채 만들기를 누르면, 화면에 "거래처명을 넣지 않았습니다"처럼 어떤 칸이 비어 있는지 이름을 짚어서 보여준다.

# 계약서 만들기

- 써 보기 : [https://contract-maker.streamlit.app/](https://contract-maker.streamlit.app/)
- 한 줄 소개 : 온라인 쇼핑몰을 혼자 운영하는 자영업자가 저장해 둔 양식·거래처를 불러와 빈칸을 채우면 계약서가 만들어지고, PDF로 내려받아 출력할 수 있는 웹 앱입니다.

같은 계약서를 매번 새로 쓰는 게 힘들어서 만들었습니다

## 무엇을 하는 서비스인가

빈칸만 채우면 계약서가 만들어지고, 바로 PDF로 내려받아 출력할 수 있는 웹 앱입니다.

- 거래처명·금액·날짜·계약내용을 넣고 "만들기"를 누르면 화면에 계약서가 펼쳐집니다.
- 저장해 둔 양식과 거래처를 골라 입력칸에 불러올 수 있습니다.
- 완성된 계약서는 `계약서_거래처명_날짜.pdf` 파일로 내려받습니다.

## 누구를 위한 것인가

온라인 쇼핑몰을 혼자 운영하는 자영업자를 위한 도구입니다.

- 다른 사업자와 상품을 거래할 때마다 계약서가 필요합니다.
- 지금은 인쇄된 양식을 찾아 손으로 작성하고 있고, 이 일이 한 달에도 여러 번 반복됩니다.
- 매번 양식과 내용을 여기저기서 찾지 않고 계약서를 완성하는 것이 목표입니다.

## 어떻게 쓰나

1. 첫 화면에서 **시작하기**를 누르면 **화면 1 - 계약서 목록**이 열립니다.
2. 화면 1에서 둘 중 하나를 누릅니다.
   - **+ 계약서 새로 만들기** : 빈 입력칸으로 시작합니다.
   - 목록의 **계약서 항목** : 그 계약서의 거래처명·금액·날짜·계약내용을 가지고 시작합니다.
3. **화면 2 - 양식·거래처 고르기**에서
   1. 저장된 양식 목록에서 양식을 고르고 **다음**을 누릅니다.
   2. 저장된 거래처 목록에서 거래처를 고르고 **적용**을 누릅니다.
   - **목록으로 돌아가기**를 누르면 화면 1로 돌아갑니다.
4. **화면 3 - 계약서 만들기**가 열리고, 고른 양식의 본문은 계약내용 칸에, 고른 거래처는 거래처명 칸에 채워져 있습니다.
5. 칸을 확인하거나 고친 뒤 **만들기**를 누르면 오른쪽에 계약서가 펼쳐집니다.
   - 비어 있는 칸이 있으면 "거래처명을 넣지 않았습니다"처럼 어떤 칸이 비었는지 알려 줍니다.
6. **다운로드**를 누르면 PDF 파일이 내려오고 "다운로드 완료"가 보입니다. "만들기" 전에는 다운로드 버튼이 잠겨 있습니다.

### 어느 화면에서나 쓸 수 있는 것

- 왼쪽 메뉴
  - **첫 화면으로 돌아가기** : 시작하기가 있는 첫 화면으로 갑니다.
  - **화면 1 · 2 · 3** : 원하는 화면을 바로 고릅니다.
  - **이전 화면으로 돌아가기** : 누를 때마다 지나온 화면을 하나씩 거꾸로 되돌아갑니다.
- 오른쪽 아래 **챗봇** 아이콘
  - **대화하기** : 말투를 고르고 물어볼 말을 넣으면 서비스 사용법을 알려 줍니다. 답 옆의 **복사**를 누르면 답을 복사합니다.
  - **지난대화** : 예전에 주고받은 대화를 최근 것부터 봅니다.
